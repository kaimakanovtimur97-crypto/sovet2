# «Совет Маркетинг» — статический Next.js-сайт

Многостраничный сайт агентства в Новороссийске. Все публичные страницы,
метаданные, JSON-LD, `robots.txt` и `sitemap.xml` генерируются во время
сборки и публикуются в Timeweb Frontend-приложении `sovet2-static` из ветки
`main`.

## Сборка

```bash
npm ci
npm run build
```

Готовые файлы появляются в `out/`. Включён `trailingSlash`, поэтому
внутренние страницы экспортируются как `/path/index.html`.

## Производственный домен

Единственный canonical-хост: `https://sovet-novoross.ru`.

- Все canonical, Open Graph, JSON-LD, `robots.txt` и URL в sitemap должны
  использовать только apex-домен без `www`.
- `www.sovet-novoross.ru` должен постоянно перенаправлять на apex с
  сохранением пути и query.
- Оба варианта старого `sovet-nvrsk.ru` должны постоянно перенаправлять на
  соответствующие URL нового домена.

Редиректы и настоящий HTTP 404 настраиваются на уровне хостинга. Статический
экспорт сам не может исправить серверный SPA fallback Timeweb.

## Контакты

На сайте нет формы заявки и серверного обработчика персональных данных.
Посетителю доступны прямой звонок и переходы в Telegram и WhatsApp по номеру
`+7 995 263 15 53`. Для MAX отображается тот же номер; прямую ссылку можно
добавить после проверки ссылки «Поделиться профилем» из MAX.

## Яндекс Метрика

Счётчик `111627787` загружается только после явного согласия посетителя.
До согласия устанавливается `disableYaCounter111627787=true`, внешний скрипт
Метрики не загружается и аналитические данные не отправляются.

Для счётчика используются JavaScript-цели:

- `contact_phone`;
- `contact_telegram`;
- `contact_whatsapp`;
- `contact_max` — начнёт фиксироваться после добавления проверенной ссылки MAX.

Навигация Next.js учитывается отдельными `hit` при смене URL. Изменить выбор
можно кнопкой «Настройки cookie» в подвале сайта.

## Проверка перед публикацией

1. Все 29 URL из `sitemap.xml` отвечают своей страницей, содержат один H1 и
   self-canonical на `https://sovet-novoross.ru/.../`.
2. В HTML, JSON-LD, `robots.txt`, sitemap и клиентском бандле нет
   `sovet-nvrsk.ru` или `www.sovet-novoross.ru`.
3. До согласия нет запросов к `mc.yandex.ru`; после согласия счётчик
   `111627787` загружается один раз и отправляет один просмотр на URL.
4. Цели контактов проверяются в отладочном режиме Метрики без передачи
   номера телефона или других идентификаторов в параметрах.
5. Телефон, Telegram и WhatsApp используют номер `+7 995 263 15 53`.
6. Apex и `www` имеют валидный TLS; `www` и старый домен делают постоянный
   редирект на новый apex с сохранением пути и query.
7. Неизвестный URL возвращает настоящий HTTP 404, а не главную страницу.
